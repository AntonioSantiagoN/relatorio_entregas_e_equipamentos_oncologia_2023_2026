# Entregas de equipamentos em oncologia 2023–2026

Relatório interativo sobre produção e habilitação de equipamentos em oncologia no período 2023–2026.

## Como abrir

- Abra o arquivo `index.html` em qualquer navegador; ou
- Ative o GitHub Pages (Settings → Pages → branch `main`, pasta `/root`) para acessá-lo online.

O relatório é um único arquivo HTML autocontido (CSS e JavaScript embutidos).
